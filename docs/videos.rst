Video tutorials
===============

A series of short videos on using, extending and analysing BLADE is in
preparation. Each episode takes 3 to 8 minutes:

.. list-table::
   :header-rows: 1
   :widths: 6 34 60

   * - #
     - Episode
     - Covers
   * - 1
     - BLADE in 5 minutes
     - Install, ``init``, ``validate``, ``check``, a first run and the web
       app.
   * - 2
     - Experiments in YAML
     - LLMs, methods, problems and suites; ``--set``, ``--dry-run`` and
       resuming.
   * - 3
     - Local and hosted LLMs
     - API keys, Ollama, vLLM with one server per GPU, ``provider: multi``.
   * - 4
     - Your own problem
     - Prompts, ``evaluate()``, the reference solution and ``check``.
   * - 5
     - Your own method
     - A ``Method`` subclass and the rules for a fair comparison.
   * - 6
     - Analysing results
     - The web app, code evolution graphs and plots in Python.
   * - 7
     - BLADE with a coding agent
     - ``iohblade skill`` and an experiment set up by an agent.

Until the videos are online, the :doc:`Quickstart` and the tutorials cover
the same steps in writing.
