\section{Discussion and Limitations}\label{sec:discussion}
\pages{0.5}

\begin{itemize}
  \item \plan{Reading is ready to use (pre-screen); writing is a weak
    but real control: behaviour moves in single generations, selection
    dilutes it in the loop. Implication: steer the selection or the
    population composition, or combine the dial with
    behaviour-aware selection.}
  \item \plan{Steering at one dose for every token perturbs the code
    unspecifically (random directions raise exploration too); report
    random-direction controls.}
  \item \plan{Limitations: open-weight models of 8--14B parameters;
    one main benchmark (MA-BBOB 5-D); high failure rates on the transfer
    problems; concept labels from code patterns; non-inferiority margin
    of 0.10 \aocc.}
  \item \plan{Benchmarks: the sandbox issues change failure statistics
    that AAD papers report.}
\end{itemize}
