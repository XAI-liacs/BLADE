\section{Background and Related Work}\label{sec:related}

\paragraph{LLM-driven algorithm design.}
FunSearch~\cite{romeraparedes2024funsearch} evolves programs with an LLM
mutation operator and an island model; EoH~\cite{liu2024eoh} evolves
thoughts and code together; ReEvo~\cite{ye2024reevo} adds reflection;
\llamea~\cite{vanstein2025llamea} runs an elitist
$(\mu+\lambda)$ evolution strategy over complete optimisation algorithms,
with refine, new and simplify prompts; and
AlphaEvolve~\cite{novikov2025alphaevolve} scales the idea to large code
bases. \blade~\cite{blade2025} benchmarks such methods on a common set of
problems. Analyses of what these methods produce have been external so
far: code features, abstract syntax trees, code-evolution
graphs~\cite{vanstein2025ceg} and the search behaviour of the generated
algorithms. None look inside the generator.

\paragraph{Learning for EC\@.}
Surrogate models and offspring pre-selection save expensive evaluations
by predicting fitness before evaluation~\cite{jin2011surrogate}. Our
pre-screen is a surrogate of a different kind: it is free, because it
reads the generator's own state while the offspring is written, and it
predicts failure rather than fitness. Our adaptive dial borrows from
step-size control in evolution strategies~\cite{rechenberg1973}: the
dose is adapted to the success of recent offspring.

\paragraph{Mechanistic interpretability.}
Linear probes~\cite{alain2016probes} test whether a quantity is linearly
decodable from a layer's activations. Sparse autoencoders
(SAEs)~\cite{bricken2023monosemanticity,cunningham2024sae} decompose the
residual stream into sparse, often interpretable features, and
attribution graphs~\cite{ameisen2025circuits} trace which input tokens
and features drive an output. Activation
steering~\cite{turner2023actadd,rimsky2024caa,zou2023repe} adds a
direction, often the difference of mean activations between contrasting
prompts, to the residual stream during generation. Prior work on code
models probes syntax and correctness of the code
itself~\todo{cite probing for code correctness}. We probe and steer a
generator embedded in an optimisation loop, and measure the effect
downstream, on the search.
